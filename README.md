# Curiosity tracker
An app to track elements of software development that I am interested in learning about

# Why I'm building this
I'd like a place that I can easily collect things I'm curious about in web development. 

This is primarily a learning project, giving me an opportunity to experiment with different technologies and software engineering practices.

# Initial features
Create, edit and delete questions
Organise questions by topic
Record notes and findings
Give questions a state - to be explored, exploring, explored
Browse and search previous explorations

# Technical interests
Some areas I'd like to explore while developing this application:
Angular and TypeScript.
Component architecture and shared state management.
Application configuration and environment variables.
Infrastructure as code with Terraform.
Secrets management with SOPS.
These are areas of interest, not fixed technical requirements.

# Development approach
Start with a small, functional application and introduce additional complexity when there's something useful to learn.
